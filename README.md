# Real Life Technologies — website prototype

Prototype of a new institutional site for Real Life Technologies. Art direction from Nuno’s mock (dark, gold ribbon, magenta/cyan sculpture). Motion and chrome from DatabyPassion (canvas hero, sticky nav, cookie banner, four-pillar layout).

This is **not** the production WordPress at [reallife.pt](https://reallife.pt/). Noindex on purpose.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind v4 · Vercel

## Local

```bash
npm install
npm run dev
```
